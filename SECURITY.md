# Segurança

## Versões suportadas

A versão mais recente recebe correções de segurança.

## Reportando uma vulnerabilidade

Não abra uma issue pública. Use a opção privada de reporte de vulnerabilidade
na aba Security do repositório e inclua impacto, passos para reprodução e uma
proposta de correção, se houver.

Evite anexar fotos pessoais, pacotes reais ou outros dados sensíveis.
