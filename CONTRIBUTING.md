# Contribuindo

Relatos de bugs e sugestões são bem-vindos pelas issues do GitHub.

O código-fonte é publicado somente para consulta. Pull requests e alterações de
código exigem autorização prévia do titular dos direitos. Abrir uma issue antes
de preparar qualquer mudança evita trabalho perdido.

Nunca publique imagens pessoais, pacotes de figurinhas, chaves, tokens ou outros
dados sensíveis em issues e logs.
